`gandalf scan` performs read-only discovery of the local agent configuration for `codex`, `claude-code`, and `cursor`. It inspects installed skills, hooks, MCP servers, plugins, and Cursor Agent CLI config without making any changes, so you can run it safely at any time to understand the current state of your setup.

## Synopsis

```bash
gandalf scan [flags]
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `-p`, `--project` | Project path | `.` |
| `--home` | Home directory path | `$HOME` |
| `--store` | Gandalf data directory | `~/.gandalf` |
| `--agent` | Target agent (`codex`, `claude-code`, `cursor`) | (none) |
| `--scope` | Scope (`user`, `project`, `managed`, `unknown`) | (none) |
| `--json` | Emit output as JSON | (disabled) |
| `--explain` | Include paths considered during discovery | (disabled) |

## Examples

### Basic scan for Codex

```bash
gandalf scan --agent codex --scope user
```

### Scan and emit JSON

```bash CodeGroup
gandalf scan --agent codex --scope user --json
gandalf scan --agent claude-code --scope user --json
gandalf scan --agent cursor --scope user --json
gandalf scan --agent cursor --scope project --json
```

### Scan with explanation

```bash
gandalf scan --agent claude-code --scope user --explain
```

## Notes

- `scan` never writes to disk. It is safe to run repeatedly.
- When `--explain` is passed, the output includes the file paths Gandalf inspected, which is useful for debugging or for understanding how agent configuration is resolved.
- Use `--json` to pipe scan output into other tools or for programmatic inspection.
- Currently supported agents are `codex`, `claude-code`, and `cursor`. Scan includes agent-native project files (for example `.cursor/mcp.json`, `.mcp.json`, `.codex/config.toml`, and Cursor `.cursor/cli.json`). Use `--scope project` to limit discovery. Generic `.env` files are not managed.
