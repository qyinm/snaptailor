# `gandalf export`

`gandalf export` scans existing Cursor, Claude Code, and Codex configurations and writes a canonical `gandalf.toml`. Export is manifest only. Secrets, logins, and agent installs are out of scope. Other machines need `gandalf apply` (agents already installed; `${ENV}` filled there).

`gandalf import` is a backward-compatible alias for the same command.

```bash
gandalf export [flags]
gandalf import [flags]
```

---

## Flags

| Flag | Shorthand | Default | Description |
|---|:---:|:---:|---|
| `--project-only` | | `false` | Restrict scan to repository files only. |
| `--from` | | | Export strictly from a specific file or directory. |
| `--dry-run` | | `false` | Preview generated `gandalf.toml` without writing. |
| `--force` | `-f` | `false` | Overwrite existing `gandalf.toml` if present. |
| `--output` | `-o` | `gandalf.toml` | Output manifest file path. |
| `--interactive` | `-i` | `false` | Launch interactive TUI wizard. |
| `--json` | | `false` | Return JSON response. |

---

## Examples

### Preview without writing
```bash
gandalf export --dry-run
```

### Project files only
```bash
gandalf export --project-only
```

### Backward-compatible alias
```bash
gandalf import --dry-run
```
